# API Reference Overview

API reference documentation for Stakater Cloud Orchestrator resources.

## Kubernetes Resources

SCO provides several custom resources for managing the platform:

- **[Organization](kubernetes-resources/organization.md)**: Logical grouping of users and projects
- **[Project](kubernetes-resources/project.md)**: Isolated environment combining KCP workspace and MTO tenant
- **[Solution](kubernetes-resources/solution.md)**: Service offering definition
- **[Solution Instance](kubernetes-resources/solution-instance.md)**: Running instance of a solution

## KCP APIs

KCP-specific resources used by SCO:

- **[Workspace API](kcp-apis/workspace-api.md)**: Virtual workspace management
